# ChengziCV 总入口 Evals

## 应路由

1. “我快毕业了，不知道该做什么，也没有简历。”应先进入职业规划，且只索取当前决定与最近期限。
2. “后天面试，这里有简历和 JD。”应优先处理最近面试；根据轮次在初筛或专项训练中只选一个。
3. “刚面完，这是录音。”应进入真实面试复盘，不从职业规划重新开始。
4. “方向明确，帮我把项目整理成简历和飞书作品集。”应进入简历 Skill，并触发飞书环境检测协议。
5. “我是大三学生，没有简历，先帮我把大作业、奖状和证书整理成求职档案。”应进入建档 Skill，不直接生成岗位版简历。
6. “我什么都没有，但主要是不知道考公还是找运营工作。”核心问题是方向判断，应进入职业规划，不强制先补完整档案。

## 首次体验

1. 用户只调用 `$chengzicv`：首次介绍应说明“1 个总入口 + 6 个执行 Skills”，可展示公开调用名与推荐路径，但不得让用户研究内部路由或先手动选择模式。
2. 用户应能从介绍中认出至少一种处境，并知道对应会拿到什么：建档是“档案快照、材料索引与待确认项”；方向是“少量方向假设和现实验证动作”；材料是“简历正文、证据缺口和追问风险”；初筛是“原话依据的判断与短复练”；专项训练是“连续追问、教学和变式复测”；真实面试是“原话诊断、逐题面经和下一场重点”。
3. “我后天有 HR 面，简历和 JD 在上面。”介绍后应优先路由到初筛模拟并直接开始，不得再问用户选哪一种服务，也不得强制职业规划或完整链路。
4. “我只有一点迷茫，不知道从何开始。”介绍后只索取当前背景或现有材料、最着急的问题和最近不可错过的日期；不得再次罗列六个执行入口或索取完整简历。
5. 用户第二次回复材料后，不重复完整介绍；应从材料和期限所支持的当前一步继续。
6. 首次介绍可以说明档案能随时补充、暂停和导出快照，但不得承诺普通聊天跨会话自动记忆。
7. 总入口完成路由后不得在同一对话中再次输出目标执行 Skill 的完整公共介绍；应把总入口介绍视为套件级 onboarding 并直接开始。用户直接调用执行 Skill 时，仍输出该 Skill 自己的完整首次介绍。
8. 首次可见文字必须从“你好，我是橙子 CV 求职导航。”开始，不得输出“首次使用公共介绍”“锁定正文”或文件说明标题。

## 不应阻断

1. 用户已经给出材料时，不要求他研究六个执行 Skill 或重新调用命令。
2. 用户只说“帮我找工作”时，不展示内部路由表，只问现有材料与最近期限。
3. 有截止日期时，不强迫从职业规划开始走完整链路。
4. 未显式调用 `$chengzicv` 的明确简历、职业规划或面试任务，不应由总入口抢走对应子 Skill 的直接路由。

## 依赖回归

- 运行包中不得出现非 ChengziCV Skill 名称或作者本机绝对路径。
- 没有持久化 Runtime 时，建档 Skill 必须交付可复制快照，不得假装自动恢复历史档案。
- 未安装 `lark-cli` 时，飞书作品集仍应先完成本地双文档，并给出经同意安装与网页回退两条路径。
- Python 校验器在没有第三方包的标准 Python 环境中可运行。
