# 面试前调研与双文档准备 Evals

只在创建、修改或回归本 Skill 时读取。正常面试准备不加载。

## 准入与历史基线

真实基线中，无专门 Skill 的完整面试准备容易出现四类问题：

- 把公司百科、岗位分析、问题答案和招聘调研塞进一份长稿，面试官与候选人都不好用；
- 同一内容反复新建“展示版、报告版、手机版、冲刺版”，最终链接失控；
- 竞品研究只列公司名称，没有落到产品线、岗位关键词、能力画像和候选人吸引点；
- 腾讯文档出现原样 `**`、未渲染 Mermaid、图片缺失或尾部内容未写入，却因接口返回成功被误判为交付完成。

本 Skill 的存在价值是把研究证据、候选人事实和两个受众的使用场景固定成可验收交付；一句“帮我准备面试”不足以稳定解决这些跨阶段错误。

## 应触发

### P1：材料齐全，明天面试

用户提供简历、JD、公司和项目背景，并说：

> 明天面试，帮我调研公司和业务，准备一份能给面试官看的材料，再给我一份今晚复习的答案手册。

通过条件：

- 首次介绍后立即开始，不让用户再次确认已给材料；
- 研究当前公司、业务、行业和岗位，并给时效性事实标注来源与日期；
- 默认只形成面试官展示稿和候选人私密冲刺稿两份活动文档；
- 展示稿能说明“这些背景怎样改变招聘或岗位工作”，不是公司百科；
- 冲刺稿包含结合候选人事实写成的完整可说答案，不只列问题提纲；
- 用户要求腾讯文档时进入富文档发布与反向校验，不把本地 Markdown 当成已发布。

### P2：材料缺失

用户只说“帮我做明天的面试准备”。

通过条件：

- 完成首次价值说明；
- 只索取当前缺少的最小材料：目标公司与岗位/JD，以及用于个性化的简历；
- 不要求先填写完整档案，不展示内部模式菜单；
- 面试时间、轮次和已有通知作为可选加速信息，不因缺失阻断。

### P3：招聘岗位的人才供给研究

用户应聘招聘专员，希望研究目标客户的不同工作室和人才来源。

通过条件：

- 读取招聘人才市场 Reference；
- 至少落实到“业务/工作室或产品线 → 岗位族 → 竞品公司 → 对应业务线/产品 → 搜索关键词 → 能力证据 → 候选人吸引点”；
- 学校和专业只能作为寻访线索，不能替代能力判断或成为排除条件；
- 外部事实、招聘推断和待内部确认项分开；
- 不宣称知道内部 HC、薪酬、项目保密信息或组织关系。

### P4：非招聘岗位

用户应聘产品经理，要求公司调研、面试问题答案和双文档。

通过条件：

- 不读取招聘人才市场 Reference；
- 把研究改成业务、产品、用户、竞争与岗位能力，不机械输出人才供给、大学专业或候选人话术；
- 仍遵守事实分层和双受众交付。

### P5：腾讯文档 MCP 尚未连接

用户要求发布腾讯文档，但当前没有腾讯文档工具或鉴权失败。

通过条件：

- 给出腾讯官方 Token 页面和 MCP 地址；
- 只有宿主提供安全凭据或 MCP 配置入口时才接收 Token；普通聊天中不索取、不回显、不落盘；
- 用户完成连接后由 Agent 做只读身份验证并继续发布；
- 用户拒绝或宿主不支持时交付可继续发布的本地源稿，明确尚未写入腾讯文档。

## 不应触发与相邻边界

- “按这个 JD 修改简历、做项目作品集”：使用 `chengzicv-resume`。
- “按简历问我五道 HR 面试题”：使用 `chengzicv-interview-mock`。
- “连续追问我的项目和技术细节”：使用 `chengzicv-interview-practice`。
- “这是昨天的面试录音，帮我复盘”：使用 `chengzicv-interview-review`。
- “介绍一下腾讯游戏”：普通公司研究即可；没有面试准备和双文档意图时不加载。

## 渐进读取

- 所有完整任务读取研究协议、双文档契约和答案写作规则；
- 只有招聘、猎头、TA 或人才寻访岗位读取招聘人才市场 Reference；
- 只有请求云文档创建、更新、协作或校验时才调用富文档发布能力；
- 只有腾讯文档工具缺失、鉴权失败或用户主动询问配置时读取腾讯 MCP 入门说明；
- 不因一次完整任务无条件加载所有平台 Reference。

## 端到端质量门

- 事实有来源，推断有推导，未知项没有被写成事实；
- 面试官展示稿可以在面试中直接展示，语气是“做了初步调研”，不冒充内部专家；
- 候选人冲刺稿适合手机复习，答案自然可说，并且不新增简历中没有的经历、数字和个人贡献；
- 完整交付默认只有两份活动文档，旧稿只有在替代品验证后才归档或移入回收站；
- 图只在关系复杂时使用，Mermaid 保留源文件并渲染 SVG；目标平台不能原生渲染时不得直接塞代码块；
- 腾讯文档反向读取到末尾，检查字面 `**`、Unsupported、空组件、图片、链接、权限和私密内容隔离；
- 没有跨模型前向测试时不得声称所有模型表现一致。
