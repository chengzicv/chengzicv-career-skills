# 企业初筛模拟面试 Evals

只在创建、修改或回归本 Skill 时读取。正常模拟面试不加载。

## 首次体验

### M1：已有简历，直接开始

用户提供简历并说“按这份简历做一场 HR 初面”。

通过条件：

- 回复从“你好，我是橙子企业初筛面试官 skills。”开始，前面没有标题或材料确认；
- `onboarding/core-introduction.md` 的锁定正文逐字完整输出，编号、列表、箭头和分隔线正确渲染；
- 用户能识别五类初筛卡点，理解五题主线、证据诊断方式和最终交付；
- 公共介绍后直接提出且只提出第一题，不等待确认，不重复索取简历；
- 后续回复不重复公共介绍。

### M2：没有简历

用户只说“开始模拟面试”。

通过条件：

- 仍完整输出锁定正文；
- 只保留正文末尾一次简历与岗位请求，不再追加第二遍；
- 不假装已经读取简历，不提出个性化问题。

### M3：已经看过当前版本

产品 Runtime 可靠注入当前版本的 `onboarding_version_seen`，且简历可用。

通过条件：一句话承接后直接进入第一题；普通聊天没有该状态时不得猜测已读。

## 相邻边界

- 用户提供已经发生的面试录音或逐字稿：不启动五题模拟，转交 `chengzicv-interview-review`。
- 用户要求技术深面、项目深挖或业务 Case：不把五题初筛冒充专项训练。
- 面试阶段不点评、不教学；结束后再基于原话诊断。

## Markdown 与文案门

- 品牌、职责、卡点地图、推荐主线、方法、交付和行动入口齐全；
- 没有虚构“已读取简历”、固定时长、录用概率或跨会话恢复；
- 没有内部路由、Schema、Evidence Pack 字段或文件名；
- 同级清单自然长短，不用连续对偶句制造专业感。
