# 招聘沟通状态与跟进手册

## 1. 核心目标

初次打招呼解决“是否值得点开”，后续消息解决“对方下一步最容易做什么”。招聘沟通不是把候选人的全部信息一次讲完，而是根据当前状态推进一个最小决策：

```text
先回答当前问题 → 补一个相关证据或必要条件 → 推进一个下一步
```

当候选人主动核验岗位时，结构改为：

```text
说明核验原因（可省） → 一次只问一个决定性问题 → 等回答后再进入下一题
```

## 2. 个性化所需的四层信息

生成任何续接话术前，依次读取：

1. **候选人事实**：真实公司、任务、工具、结果、交付物和可解释边界。
2. **JD 重点**：最关键的 2—3 个动作、硬门槛、岗位层级和风险词。
3. **对话状态**：招聘者刚刚问了什么、已经知道什么、下一步缺什么。
4. **候选人边界**：城市、薪资、到岗、工作性质、出差、班次、业绩结构等真实偏好。

没有候选人事实支撑的内容只能写成待替换占位符，不能把通用模板当成成品。

## 3. 状态路由

| 当前状态 | 本条消息的唯一目标 | 推荐结构 | 下一步 |
| --- | --- | --- | --- |
| 对方索要简历 | 发送正确岗位版并加强一个匹配点 | 已发送 + 版本名称 + 一项证据 | 等对方查看 |
| 对方问是否有相关经验 | 直接回答并给最相似案例 | 结论 + 动作 + 结果/交付物 | 询问是否需要材料或沟通 |
| 对方核对学校、届次、城市、到岗 | 消除硬筛疑问 | 真实结论 + 必要说明 | 询问下一步安排 |
| 对方问薪资 | 给区间和口径，不绕开问题 | 期望区间 + 综合考虑项 | 等岗位预算反馈 |
| 岗位名称或 JD 含糊 | 判断是否值得继续 | 一次只问职责、考核或工作场景中的一个 | 按回答继续核验 |
| 对方说“可以聊聊” | 承接意向，降低下一步成本 | 相关证据 + 文字/2分钟电话二选一 | 等对方选择 |
| 对方提出电话但未打来 | 避免错过意向窗口 | 客观观察 + 轻松提醒 + 随时可接 | 当日提醒，次日可再确认 |
| 对方邀请面试 | 快速锁定时间和形式 | 确认可行时段 + 联系方式/形式 | 准备面试 |
| 候选人需要改期 | 降低安排成本 | 简短致歉 + 2 个替代时段 | 等确认 |
| 对方说“等通知/考虑一下” | 确认合理反馈节点 | 感谢 + 询问预计时间 | 到节点后最多跟进一次 |
| 面试后仍在等待 | 获取明确进度 | 岗位/面试日期 + 继续意向 + 进度询问 | 有结果则结束或推进 |
| 已读不回 | 提供一个新的打开理由 | 新证据 + 低压力入口 | 普通岗位一轮；重点岗位可继续一至两轮 |
| 明确拒绝 | 获取可复盘信息 | 感谢 + 小选项问题 + 退出空间 | 回复后道谢并结束 |
| 岗位关闭/暂停 | 保留未来机会 | 感谢 + 是否可保留材料 | 结束 |

## 4. 常用状态模板

模板里的方括号必须用真实信息替换；无法确认时保留为“待确认”，不能自行补造。

### 对方索要简历

> 可以，已发送【岗位方向】版简历。补充一句，我在【经历】中做过【最相关动作/结果】，与 JD 里的【关键词】直接相关；如需【作品/证明材料】，我可以继续补充。

若附件刚刚已经发送，不重复问“方便看看吗”。

发完简历、对方已经表现出初步意向时，可以补一条：

> 我这边随时可以接电话，如果需要进一步了解，电话沟通2分钟或直接文字问我都可以，合适的话后续再推进就好～

### 对方问“有相关经验吗”

> 有，最接近的是【经历】。我具体负责【动作1、动作2】，交付了【结果/材料】；其中【某项】与这个岗位的【JD任务】比较一致。

没有完全同岗经验时要诚实划界：

> 没有完整的【目标岗位】正式经历，但做过其中的【相似任务】。在【经历】中，我负责【动作】，产出【交付物/结果】；如果岗位接受初级候选人，我可以进一步发案例说明。

### 对方问求职动机或为什么匹配

> 我选择这个方向不是临时尝试。过往【经历A】和【经历B】里，我持续承担【共同动作】，也更擅长【能力】；这和岗位需要的【JD重点】是一致的。

### 对方核对到岗、城市或当前状态

> 我目前【在职/离职/在校/已毕业】，工作地点考虑【城市】，最早可在【日期】到岗；如果流程确定，也可以提前配合完成面试和材料准备。

### 对方问期望薪资

> 我目前期望【税前月薪区间/年薪区间】，也会结合岗位职责、固定与浮动构成、福利和成长空间综合沟通。请问这个岗位目前的预算范围大概是多少？

不要虚构历史薪资，也不要用“都可以”回避。

### 主动确认岗位真实职责

不要泛问“岗位职责是什么”，优先问可区分岗位性质的真实场景：

> 想确认一下，这个岗位入职后的前三项核心工作，主要是【A】、【B】这类执行支持，还是需要独立负责【C】？

> 想确认一下，这个岗位试用期最主要的考核，是【流程/交付/响应】还是【销售额/续费率/转化】？

> 想确认一下，客户沟通主要偏【需求收集与项目协调】，还是也需要【独立开发客户与商务应酬】？

> 想确认一下，岗位是否需要出差或驻场？大致频率和单次周期是怎样的？

> 想提前了解一下团队的常规工作时间，以及集中加班通常发生在哪些节点。

一次只发其中最关键的一问。职责还未确认时先问职责；职责匹配后再问考核、出差和工作时间。

### 对方说“可以聊聊”

不要立刻要求对方现在打电话。先补最相关的工作证据，再把电话变成可选项：

> 可以呀。我做过【岗位动作1】、【岗位动作2】，和这个岗位的【JD重点】比较贴近。您可以直接文字问我；需要进一步了解的话，我也随时可以电话沟通2分钟，合适再继续推进就好～

### 对方说想电话沟通，但当天没有打来

第一轮，数小时后或合理工作时段内：

> 哈喽呀～看您前面有提到电话沟通，但我这边还没接到，猜你可能在忙。我随时可以接电话，您有空直接call我就行；文字沟通也可以哈～

第二轮，次日仍无进展：

> 哈喽呀～前面沟通后一直没收到电话，我有点担心错过消息。我对【岗位】确实很有意向，也做过【相关经历】。如果只是最近比较忙，您有空随时联系我；如果岗位暂停或关闭了，也可以直接告诉我哈～

这里的“有点担心错过”是本人感受，不是向招聘者施压。不要连续拨打电话，也不要擅自使用私人联系方式。

招聘者显示离线不代表拒绝，也可能是状态隐藏或没有及时刷新。不要反复盯在线状态；按已经释放的意向和合理工作时段发送即可。

### 接受面试

> 可以参加，感谢邀请。【日期/时间段A】或【日期/时间段B】我都方便，请问面试是【线上/线下】，预计多长时间？确认后我会提前准备。

### 申请改期

> 抱歉，【原时间】临时有【可简述的客观原因】，想申请调整。我在【替代时段A】或【替代时段B】都可以配合，给您添麻烦了。

### 对方说“等通知”

> 好的，谢谢告知，我会保持电话和平台消息畅通。想确认一下，预计会在【本周/几天内】有下一步结果吗？我好安排后续时间。

### 面试后致谢

不是每场都必须发送。高意向岗位且确有新增信息时，可在当天发送：

> 感谢今天的沟通。面试中提到的【岗位重点】让我更确认这个方向与我做过的【相关经历】契合；如需补充【材料/案例】，我可以随时发送。

### 面试后未收到结果

优先等到对方承诺节点；没有承诺时，可在约 3—5 个工作日后低压力询问一次：

> 我在【日期】参加了【岗位】面试，想了解一下目前的招聘进度。我对岗位仍有意向，如需补充材料或安排下一轮，我都可以及时配合。

### 已读不回

普通岗位在初次触达约 24—48 小时后跟进一轮；重点意向岗位可以分 2—3 轮触达，但每轮必须增加信息或改变目的。

第一轮建议拆成三个短消息气泡：

> 看到您看过我的消息啦～

> 补充一个和岗位直接相关的信息：我在【经历】中做过【新动作】，产出【新结果/交付物】，如果方便可以把详细材料发您。

> 我对【岗位】确实很有意向，文字或电话沟通都可以；如果岗位暂停了也可以直接告诉我哈～

重点岗位第二轮可在次日或另一个合理工作时段发送：

> 想再确认一下咱们岗位目前是否还在推进。我这边做过【另一项匹配证据】，也愿意长期往这个方向发展；如果暂时不匹配，直接告诉我也没关系～

第三轮只用于对方此前明确释放过兴趣、索要过简历或约过电话的情况，重点是确认进度或岗位状态，不再重复卖点。

### 明确拒绝

建议拆成三个短消息气泡：

> 好的，谢谢您告知～

> 方便的话想请教一下，主要是【行业经历】、【岗位层级】还是【核心技能】不太匹配？对我后面调整方向会很有帮助。

> 不方便回复也完全没关系，感谢您的时间～

对方反馈后：

> 明白了，谢谢您愿意说明，我会据此补充和调整。祝招聘顺利。

### 岗位暂停或关闭

> 明白了，谢谢告知。如果后续有【同方向岗位】开放，方便的话希望可以继续保留我的简历；祝招聘顺利。

## 5. 候选人边界如何中性表达

不要把偏好写成情绪或对企业的预设判断。先确认岗位事实，再决定是否继续。

| 候选人真实边界 | 不推荐 | 推荐核验 |
| --- | --- | --- |
| 不接受强个人业绩 | 我不想有压力 | 试用期主要考核流程交付，还是个人销售额/续费率？ |
| 接受销售支持，不做陌生开发 | 我不做销售 | 客户沟通偏项目支持，还是需要独立获客？ |
| 不接受高频出差 | 我不能出差 | 出差大致每月几次、单次多久？ |
| 不接受频繁应酬 | 我不喜欢应酬 | 商务沟通以线上/会议为主，还是需要高频线下宴请？ |
| 关注双休和加班 | 我只想轻松 | 常规工作时间怎样？集中加班通常发生在哪些节点？ |
| 担心行政岗变销售 | 这个不会是挂羊头卖狗肉吧 | 核心交付偏资料流程和内部协调，还是承担个人业务指标？ |

## 6. 停止条件

出现以下任一情况即停止主动追问：

- 普通冷岗位已经补充过一轮仍无回复；
- 重点意向岗位已完成 2—3 次不同目的的触达，仍没有任何回应；
- 对方曾表达电话或沟通意向，但当日提醒、次日确认后仍无推进，且没有新的招聘信号；
- 明确拒绝后已完成选项式提问；特别需要复盘时最多再做一次极短收口，仍无回复或已经答复后停止；
- 对方说明岗位已关闭、暂停或已有合适人选；
- 核心条件明确不匹配，且没有合理协商空间；
- 对方要求付费、贷款、押金、刷流水、提供验证码或不必要的敏感证件；
- 对方持续回避公司主体、办公地点、职责、薪资结构等基本信息。

停止不是失败，而是把时间转向更可能进入下一步的岗位。

## 7. 交付检查

- [ ] 每条话术标明适用触发场景，用户知道什么时候发。
- [ ] 先回答招聘者问题，没有用自我介绍绕开。
- [ ] 个性化话术至少引用一项候选人真实经历、动作或结果。
- [ ] 候选人的城市、薪资、到岗和工作边界没有被擅自承诺。
- [ ] 主动追问一次只问一个决定性问题。
- [ ] 已读不回和拒绝后的频率符合停止规则。
- [ ] 话术口语化、可直接复制，不像正式邮件或 Cover Letter。
