# 技术简历规则

技术简历要同时照顾两类读者：

- HR：不一定懂技术，但要看懂这个项目解决什么问题、和 JD 有什么关系。
- 技术面试官：会看技术事实、技术边界、实现动作，不能乱写术语。

## 核心原则

1. 不新增用户没提过或没确认过的技术。
2. 技术名词必须落到行为，不要只堆栈。
3. 项目背景要讲人话，不能只有框架名。
4. 写得能自然引出追问，而不是把所有细节塞满。
5. 不要把学生项目写成企业级架构。
6. 每条职责 bullet 使用加粗小标题，让 HR 和技术面试官能快速定位模块。
7. 保留材料支持的实现层差异点，但用完整句子和分号控制阅读负荷，不靠符号堆叠压缩信息。

## 技术项目结构

推荐：

```text
项目名 | 角色 | 时间
**项目背景**：一句话说明这个项目给谁用、解决什么问题。
**技术栈**：只列真实使用技术。
**我的职责**：
- **模块名称**：具体实现动作 + 技术机制 + 结果。
- **问题排查**：遇到什么问题，怎么定位，怎么处理。
- **联调上线**：和谁协作，怎么验证。
**成果**：上线、演示、通过验收、服务用户、性能变化等真实结果。
```

职责 bullet 的小标题是硬格式，不要输出成下面这种无标题写法：

```text
- 实现双后端流式输出，并对工具进行并发调度……
```

应写为：

```text
- **Agent 工具系统**：实现双后端流式输出，并按工具副作用安排并发与串行执行……
```

### 技术细节与可读性的平衡

- 项目背景先交代场景定位，再归纳 2-3 个核心问题；只有用户材料明确出现领域术语时才保留该术语。
- 小标题负责分类，正文负责证明。不要用“系统优化”“核心能力”等标题代替具体模块。
- 保留能体现设计取舍的细节，例如并发批切片、失败串行回退、三重文件校验、分级压缩和缓存边界。
- 将一条 bullet 组织为“关键动作；约束或机制；结果”，必要时拆成两句。
- 避免连续使用 `/`、`+`、`→`；技术名、路径或固定枚举本身需要斜杠时除外。

## 技术栈写法

可以写：

```text
**技术栈**：React / TypeScript / Spring Boot / MongoDB / Redis
```

但后面的 bullet 里至少要出现部分技术对应的动作：

```text
- **登录鉴权**：用 Spring Boot 实现登录接口，接入 JWT 鉴权，并和前端联调 token 过期后的刷新逻辑。
```

不要只写：

```text
技术栈：React、Spring Boot、MongoDB、Redis、Docker、K8s、微服务、分布式。
```

如果原文没有 K8s，不要补。宁可少，也不要假。

## HR 可读改写

技术太重时，要补业务对象。

原文：

```text
基于 YOLOv8 完成目标检测模型训练，mAP 提升。
```

改写：

```text
- **缺陷识别模型**：围绕产线图片中的缺陷识别场景，使用 YOLOv8 训练检测模型，并根据误检样本调整标注和训练集划分。
```

这样 HR 知道是缺陷识别，技术面试官也能追问 YOLOv8、样本、mAP。

## 技术面站得住

不要为了好懂把技术写成外行话。

错误：

```text
用人工智能技术让系统更聪明。
```

正确：

```text
- **问答生成链路**：接入 Qwen2.5 作为问答模型，结合向量检索返回候选知识片段，再把检索结果和用户问题拼接给模型生成回答。
```

## 量化结果

有真实数据就写：

```text
接口平均响应从 800ms 降到 300ms。
人工评测准确率从 65% 提升至 85%。
日均处理 1 万条咨询。
```

没有数据不要编，可以写：

```text
完成后台管理端主要页面开发，并支持测试环境演示。
上线后用于内部客服检索知识库。
通过课程答辩，完成核心功能演示。
```

## 技术夸大风险

这些说法要谨慎：

- 高并发
- 分布式
- 微服务
- 企业级
- 工业级
- 高可用
- 海量数据
- 大模型微调
- 自研模型
- 架构设计

如果原文只是课程项目，不要写“企业级高并发系统”。可以写：

```text
按前后端分离方式完成用户登录、数据增删改查和基础权限控制。
```

## 技术岗个人优势示例

```text
- **RAG知识库问答系统开发**：参与搭建基于 Qwen2.5 的知识库问答系统，配合完成知识切分、向量检索和回答效果评测。

- **Spring Boot接口开发**：可完成登录、用户信息、简历保存等基础业务接口开发，熟悉参数校验、JWT 鉴权和接口联调流程。

- **Python / Pandas数据处理**：用 Pandas 清洗 Excel 和 CSV 数据，完成字段统一、缺失值处理和基础统计。
```
