# 写法案例

这些案例用来校准风格。不是让你机械复制，而是让你记住写作颗粒度。

## 数据分析

差：

```text
具备良好的数据分析能力，能够支持业务决策。
```

好：

```text
- **渠道转化分析**：用 SQL 拉取用户报名、到课和付费数据，用 Excel 透视表对比不同渠道转化差异，协助团队调整活动投放重点。
```

## 产品经历

差：

```text
参与产品需求分析，提升用户体验。
```

好：

```text
- **登录问题梳理**：整理 20 条用户反馈，按登录失败、信息填写、页面跳转 3 类问题归档；用 Axure 补充异常提示原型，并和开发确认字段校验规则。
```

## 运营经历

差：

```text
负责社群运营，提升用户活跃。
```

好：

```text
- **社群咨询优化**：维护 3 个求职社群，每周整理高频问题和报名转化数据，调整群公告和活动提醒话术，减少重复私信咨询。
```

## 技术项目

差：

```text
基于先进架构完成系统搭建，显著提升系统性能。
```

好：

```text
- **登录鉴权联调**：用 Spring Boot 实现简历保存和查询接口，接入 JWT 鉴权；通过日志排查 token 过期导致的 401 问题，并和前端联调刷新流程。
```

## AI 项目

差：

```text
参与大模型应用开发，赋能知识库问答场景。
```

好：

```text
- **知识库问答评测**：参与搭建知识库问答流程，负责整理文档切分规则和测试问题集；接入 Qwen2.5 后，对比不同 prompt 下的回答准确性和引用完整度。
```

## 财务 / 审计

差：

```text
负责财务数据核对，保证数据准确。
```

好：

```text
- **账表差异核对**：使用 VLOOKUP、SUMIF 核对总账、明细账和报表数据，整理差异清单给主管复核，减少手工漏查。
```

## 职能流程

差：

```text
优化内部流程，提高团队协作效率。
```

好：

```text
- **报修流程梳理**：梳理从客户报修、客服登记到工程师上门的 10 个步骤，制作 SOP 检查表，减少信息漏填和重复沟通。
```
