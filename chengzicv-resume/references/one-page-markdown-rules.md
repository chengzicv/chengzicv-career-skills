# Markdown 篇幅与版面规则

默认交付纯 Markdown，文风以 `plainspoken-resume-style.md` 为准。完整简历在材料足够时以约 60～65 个逻辑行为篇幅参考；不得为了凑行数增加空行、重复内容、无关经历或虚构数据。

Markdown 的逻辑行数与 PDF 的视觉行数不同。字体、字号、页边距、列表样式和句子长度都影响页数。只有查看实际渲染结果以后，才能确认是否一页；不承诺任何编辑器导入都必然一页。

## 排版选择

- 使用常规简历标题、自然段和单层 `- ` 列表，不嵌套圈号与子列表。
- 每个列表项在源文件中完整写成一行，不在句子中手动断行。
- 按 CommonMark 在标题、段落和列表之间保留必要空行，相邻列表项之间不用空行。
- 项目标题交代时间、名称和真实角色。背景与成果用自然句，默认不加三段标签。
- 单条约 35～45 个汉字只作参考。先保证一句话讲清一件事，保留专业词、异常处理与数字口径，再去冗余。
- 加粗集中在少量核心实体和结果，不加粗整段，不硬卡 15%～20%。

## 「个人优势」块的篇幅预算

「个人优势」按 `advantage-block.md` 分配：层数按材料定（默认 3 段），正文全块 150～400 字，单层背景 45～130、能力 50～130、产出 70～120、荣誉 45～120。每层占一个列表项，源文件里各写一行。

一页简历压到 150～300 字、3 段以内。材料多、用户要求保留全部细节，或本身按两页排版时才放到 5 段接近 400 字。字数只算 `## 个人优势` 标题下的正文；块后给用户的追问清单不计入，也不与正文混排。

## 篇幅取舍

优先留下最相关的工作、代表项目、关键成绩与必要资质。工作范围和项目过程可以互补，不重复整段。材料很少时允许更短；材料充分或用户要求保留全部细节时，先保持事实完整，再按实际排版调整。

小抄与内部核实说明独立于简历正文，不为了满足一页目标删掉其记录。正文不用放生成过程、顾问判断或核实清单；候选经历的实际完成阶段仍需准确表达。
