# 直述体项目示范

以下两个示例均为虚构的格式与措辞练习。人物、工具、动作与数字不能直接当作当前候选人的经历。默认写法以 `plainspoken-resume-style.md` 为准；示例没有要求每条带数字或强制标签。

## 技术项目示例

示例材料设定：三人课程团队为班内 42 人做实验课报名系统；本人负责报名接口与并发处理，使用 Spring Boot 和 MySQL。本机 JMeter 自测 100 个并发请求争抢 10 个名额，得到 10 条成功记录，无超额报名；交付接口文档和本地 Demo，取消报名后的名额归还尚未实现。

```markdown
**课程项目　实验课报名系统　报名接口开发**

为班内 42 人提供实验课报名，处理微信群接龙中的重复占位。我在三人团队中负责报名接口和并发处理，其他成员完成页面与排课。

- 使用 **Spring Boot 和 MySQL** 开发报名接口，用条件更新扣减名额，更新行数为零时返回名额已满。
- 为用户 ID 与课程 ID 设置唯一索引，阻止重复报名；事务失败时回滚名额扣减。
- 对比前端禁用按钮与数据库校验，保留数据库校验，处理刷新页面后仍可重复提交的问题。

本机使用 JMeter 发起 **100 个并发请求争抢 10 个名额**，得到 10 条成功记录，没有超额报名。交付接口文档与本地 Demo；取消报名后的名额归还尚未实现。
```

数字只出现在设定有测试证据的地方。必要的“尚未实现”保留完成边界；没有线上运行数据，不写生产性能。

## 业务项目示例

示例材料设定：本人使用 Excel 登记同学的闲置教材，每周核对重复书目；未统计人数或转化结果，已完成登记表。

```markdown
**校园项目　闲置教材登记　登记表整理**

为同学登记闲置教材，整理书名与联系方式，方便查找登记信息。

- 使用 **Excel** 录入书名和联系方式，每周核对重复书目，整理登记记录。

完成闲置教材登记表。
```

材料少时允许项目更短。已有成果是登记表，不增加成交量、覆盖人数或效率提升。两个示例展示结构密度怎样跟随材料，而非让所有岗位套同一套工程机制。
