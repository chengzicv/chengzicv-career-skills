# 个人优势块写法标准（层叠事实式）

现行标准，2026-10-14 全量重构。来源：金饭婉《28 条简历个人优势已 offer》修改前后对照，28 个真实 offer 案例。前身是 2026-10-13 的推荐理由式结构（3-4 行、≤200 字，猎头推荐语 + GodSU 片段式），现降为附录里的可选压缩变体。

分工：本文件管「个人优势」块；`plainspoken-resume-style.md` 管正文句式；`dynamic-jd-ats-engine.md` 管 JD 关键词对齐。三份同时对同一份简历生效，冲突时以本文件为准。

## 一、来源实测分布（规则的事实依据）

写规则前先量过来源，28 例「修改后」的实际形态是：

| 项 | 实测 |
| --- | --- |
| 段数 | 3 段 21 例，4 段 3 例，2 段 3 例，5 段 1 例 |
| 全块字数 | 139～400 字 |
| 分层字数 | 背景 48～126、能力 52～124、产出 74～117、荣誉 47～120 |
| 标签 | 出现 26 个词库外的段标签（团队管理、业务管理、门店管理、项目管理、品牌传播、营销策划、爆品打造、职业特征、能力素质、兴趣爱好……） |
| 结构 | 产出层只出现在 11/28 例；荣誉类信息有 4 例嵌在背景层或产出层而非独立成层 |
| 占位 | 11 例保留了 XX / X /（）占位（那是出版脱敏，不是写作规范） |

**结论：三段是常态，四段是上限，层是可选的。** 规则按这个分布写，不按「四层齐全」写。

## 二、这个块是什么

个人优势块是冠以 `## 个人优势` 标题的独立模块，放在姓名与联系行之下、专业技能之前。不允许无标题裸段落直接跟在联系行后面；联系行与块之间不再放定位句，锚点（博客、作品集、GitHub）挂在联系行，材料未提供不虚构。

它按事实维度分层回答「这人多大盘子 → 会什么 → 做出过什么 → 谁认可过」：

| 职能层 | 读者的问题 | 可选 | 事实类型 |
| --- | --- | --- | --- |
| 1 背景层 | 这人多在哪个盘子里、最硬的信号是什么 | 必有 | 学历性质、年限、行业、公司层级或名称、角色、管幅；海投时另加最硬的成果数字或岗位相关覆盖范围 |
| 2 能力层 | 会什么、怎么做 | 必有，可拆成 2～3 个能力域层 | 能力域 + 具体工作对象、方法、工具、覆盖范围 |
| 3 产出层 | 做出过什么 | 有成果才写 | 1～3 个案例：动作 + 数字 + 口径或对比 |
| 4 荣誉层 | 谁认可过、还有什么 | 有材料才写 | 奖项证书全称与级别、资源人脉、岗位相关的兴趣与持续行为 |

它不是：自我评价（认真负责、抗压能力强）、技能清单（那是专业技能区）、正文摘要（正文是证据，头部是结论）、第三人称吹捧（简历上候选人就是自己的顾问，用第一人称事实陈述）。

## 三、层标签词库（开放，不是白名单）

段标签的作用是让读者三秒定位，所以用来源里真实出现过的高频标签，按职能归位：

- **背景层**：职业背景 / 从业经历 / 背景经历 / 核心经验 / 从业背景 / 背景信息 / 产品能力（第 6 例把能力写进首层）
- **能力层**：专业能力 / 关键技能 / 专业技能 / 能力才干 / 专业功底 / 能力专长 / 能力素质 / 擅长方向 / 关键价值 / **按能力域拆分**：团队管理、业务管理、门店管理、项目管理、品牌传播、营销策划、内容创作、客户成功、活动主持、爆品打造、运营品牌、影响能力、管理理念
- **产出层**：职涯亮点 / 重点产出 / 亮点成绩 / 职业能力 / 创新能力 / 客户成功
- **荣誉层**：奖励荣誉 / 荣誉奖励 / 资源人脉 / 综合素质 / 职业特征 / 风格特质 / 职业展望 / 兴趣爱好 / 团队合作

规则：

1. 标签只能起名，不能替代事实。第 6 例「团队合作：怼的了需求，撩的了技术」这类网络化标签只在候选人是互联网产品、内容等风格匹配的岗位时用，其余岗位用平实标签。
2. 同一职能的多段可以拆开写（团队管理 + 业务管理 + 客户成功），这是来源里最常见的写法，比硬塞进一个「专业能力」层更清楚。
3. 层名与层的职能错位不算致命，但要避免硬凑：第 21 例把背景信息标成「职涯亮点」、第 9 例「关键价值」实际写的是能力，都是可接受的松弛用法，但优先让标签对得上内容。
4. 荣誉类信息可以嵌在背景层收尾（第 11 例获奖写在第 1 层）或产出层收尾（第 3 例的「客户颁发荣誉奖状」），也可以独立成层；产出层还可写「职业线上升发展」这类成长线（第 1、21 例）。不强制荣誉必须单独一层。

## 四、每层怎么写

### 第 1 层 背景层

第一句先给量，要件按重要性排：年限 → 行业 → 公司层级或名称 → 角色与管幅。

```text
- **职业背景：** [学历性质与专业]，[N] 年[行业][职能]经验，[公司层级或名称]任职经历，[真实角色]，最高带过 [N] 人团队。
```

- 年限按材料写，允许来源里常见的写法：「8+ 年」「10 年以上」「9 年+」「3 年」。材料没写年限就列入追问，不推算——来源作者能在修改后补出年限，是因为他手里有完整简历，不是靠推断。
- 公司层级要写：国企、上市公司、世界 500 强、行业头部、互联网知名公司、行业黄埔军校。公司名可查时写全称，不可查时写层级；来源里也有把公司名写成「某 X 公司」的半脱敏写法，本 Skill 不采用，一律回问。材料既没给名也没给层级时列入追问，不编一个。
- 多个机构名可以并列成串（第 8、9、12、21、23 例都是这么写的），不要为省略而写成「多行业头部公司」。
- 角色写真实职级，不升级也不降级；上升型职涯线允许写在这一层。
- **这一层装两件事：定位 + 押注信号。** 定位是年限、行业、公司层级、角色管幅；押注信号是海投时最硬的成果数字，或与目标岗位最相关的能力域与覆盖范围。来源第 18 例的第 1 层写了约 90 字，把测试范围（智能驾驶、影音娱乐、导航系统、语音识别）与「组内有效提单量位列第一」都装在里面——不要为了「一层一个主题」把范围和名次拆到后面几层，最硬的信号掉到第四行就等于没写。
- 学历按材料原样写统招与否、本科还是硕士、院校层级（985、211、QS 排名），不美化也不隐瞒。**材料只说层次或院校层级、没写统招/全日制/本硕时，不补写**，列入追问——国企与校招场景会核这一项，补错比不写更糟（第四轮回归里就出现过材料只写「211 计算机本科」、输出自行补出「统招」的情况）。
- 起止年限不明时只写年限不写年份，不拼日期。
- 在职状态、连续在职、同城、可到岗时间属于这一层的稳定可靠型信号，不进能力层——国央企与外包岗会先找这一行。

### 第 2 层 能力层（可拆多段）

写法：一个能力动词挂一个具体工作对象，对象后面再挂覆盖范围或方法。

允许的动词：**精通 / 擅长 / 熟悉 / 掌握 / 具备 / 持有 / 能 / 独立处理 / 独立完成 / 搭建 / 制定 / 审核 / 推进**。前六个在来源里是主力词（掌握、具备、持有共出现在 7 例），不要因为「显得不够硬」而换成别的。

```text
- **专业能力：** 擅长[具体模块]，包括[对象 1]、[对象 2]、[对象 3]；熟悉[制度/流程/法规/系统]；能[动作]，[覆盖范围]。
- **团队管理：** [具体管理动作 1]、[动作 2]、[动作 3]。
- **业务管理：** [体系/流程/标准/风险类动作 + 覆盖范围]。
```

- 并列项按目标岗位相关度排序，同类合并成一项；上限 8 项（来源最高一例是 8 项、另一例 7 项），超过 8 项说明在堆清单。
- **一层只放一个能力域。** 团队管理与业务管理、技术能力与项目管理、法规支持与文书合同审查都属于不同能力域，各占一层。判据：同一层里出现两组以上不同的「动词—对象」对（如「掌握法规」与「审查合同」），就拆层。把两个域压进一个「专业能力」层会立刻撑到 10 项并列、超字数上限。
- 工具与系统带名称：精通 SAP、熟练用友金蝶、熟悉 CANoe 基本操作、熟练运用 Excel 函数公式做数据分析、熟练掌握 Axure、Visio、PPT、墨刀。不写「熟练使用办公软件」。
- **语言能力单列一项**（来源 7 例有）：英语听说读写流利、英语可作为工作语言、能与跨国团队和海外客户顺畅沟通；带等级或考试成绩时写原口径（CET-6、托福 104、GRE 319）。
- 证书默认并入本层（专业功底 / 关键技能），带全称和等级：法律职业资格 A 证、中级会计师、税务师、PMP、ACCA 准会员、CPA 专业阶段 6 门通过；材料证书多时可单列一层「资质证书」。不写「持有多项证书」。
- 「怎么做」的方法与流程写在本层（结合本地日志与总线数据定位问题、通过数据分析迭代服务策略）；结果写进产出层，同一件事不在两层重复。
- **能力层不承载结果。**「通过等保三级测评」「近 3 年绩效 2 次 A」「获优秀员工」「客户 0 投诉」这类结果属于产出层或荣誉层；把它们写进能力层，产出层和荣誉层就被吃掉了（第五轮回归里 211 政务开发那一例就是这么塌成 3 层的）。
- **对象清单只能来自材料。** 材料说「公文写作是强项」，不得自行补出「发言稿、年终总结、分析材料」这些材料没提的文体；材料说「负责培训」，不得补出「编写课件并授课」这些没提的动作。
- 能力层可以只有抽象能力词 + 覆盖范围（第 17 例「具备 ERP 和 SAS 产品规划、实施交付、用户培训能力」就没有细化对象），但同层至少有一项落到具体对象，不允许整层都是抽象能力。
- JD 有明确能力词时用 JD 原词（精确匹配优先，见 `dynamic-jd-ats-engine.md`），但**只搬名词性能力词，不搬评价词**：JD 写「Java 基础扎实」，写成「用 Java 做政务信息化系统核心开发」，不写「Java 基础扎实」——评价词没有对象，一搬就把能力层变回形容词。同理，JD 的「精通」「熟悉」不直接拿来贴在候选人身上。
- 通用办公软件不单独成条；与专业工具并列（Axure、Visio、墨刀）或带具体用途（函数公式做数据分析）时可以写。

### 第 3 层 产出层（有成果才写）

1～3 个案例，每个案例一句话：在[公司、项目或场景]，[动作]，[结果数字]；[对比或口径]。

```text
- **职涯亮点：** 在[公司]，通过[动作]，为企业年创收 [600-800] 万；[项目]合同金额 [4.5] 亿，通过谈判索赔及补偿款 [1000] 万。
```

- 数字带口径：年度还是累计、个人还是团队、单次还是整体、单一平台还是整体业务，写清楚。「单一平台最高年交易额 600W 美金」「年采购金额 1-2 个亿」「当天类目排名从 50 名上升到第 2 名」都是来源原口径。
- 有前后对比的写对比，对比比绝对值更有信息量：交付周期从 60 天缩短至 45 天；库存由 24 万降至小于 5 万；审批流程从 15 条缩短至 10 条；通过分立税筹累计节税 3184 万。横向对比（出租比自用低 40-50 万）同样有效，别把它写成前后对比。
- **排名与名次类成果要连起来写**：对象 + 候选人的动作 + 评级/名次/奖励的关系可读。个人名次与团队名次、单次与累计奖励分清，官方等级和时间保持原样。「最高单洞奖励」这类原始口径不自动归到旁边的案例上。
- 没有业绩数字时，用规模、体系、覆盖范围或可验证状态承载：最高管理 500 人团队、从 0 到 1 建设客服运营管理体系、重大投诉处理与内容风险监控、零纰漏、业界首例、公司采纳、客户 0 投诉、客户颁发荣誉奖状。管理岗与职能岗整层没有业绩数字不算缺陷。
- 全块至少一处可核对量（年限、管幅、金额、数量、比例）。一处都没有时先回问用户。
- 可验证状态的适用范围必须与材料原口径一致，不得收窄或外推：材料说「任职期间零纰漏」，不写成「审查各类合同零纰漏」。
- 每个数字都能逐个指回原材料；不做加总、推算或改单位口径；材料给出的年限口径也不在头部改写（材料写 15 年就写 15 年，不改成「10 年以上」）。
- **材料里显式写出的结果性短语不能在改写中消失**：并通过测评、公司采纳、试点转正、提前转正、通过验收、获批、获客户感谢信——改写的目标是换说法，不是把结果抽象掉。动作留在能力层还是产出层都可以，但结果必须有一处出现（第六轮回归里「主导等保三级整改**并通过测评**」的测评结论就整块丢了）。
- 「从 0 到 1」是来源 4 例在用的合法表述（建体系、建品牌工作体系、拓店、产品奠基），可以用。

### 第 4 层 荣誉层（有材料才写）

按材料选一组，不硬凑：

- **荣誉与奖项**：全称 + 级别 + 年份。「所带团队评为『省级安全优秀班组』『市级巾帼文明岗』『先进集体』，个人评为『市级最美青工』『先进个人』；2020 年被省级部门选派赴美国高校访学；2021 年被集团选拔为优秀青年干部到兄弟单位交流。」团队奖项与个人奖项分开写；材料没给年份就不写年份，列入追问，不推算。
- **资源人脉**：写具体机构或渠道名。把候选人真实合作过的媒体、平台或渠道逐个写名（如〔垂直媒体名〕〔财经媒体名〕〔电视台栏目〕〔全国性报纸〕，方括号处填真实机构名），不写「行业资源丰富」这类概括。
- **综合素质**：只写有证据的行为与对象，不写性格形容词。材料提供了能落到对象的协作行为时写出来（与多部门合作定位问题归属、与开发人员沟通修复建议），不整条删除；纯性格词才删。
- **绩效与考核评级**（绩效 2 次 A、连续两年考核优秀、调薪幅度部门最高）属荣誉类，放本层或与荣誉合并收尾，不放产出层——它没有场景与动作，读不成案例。
- **兴趣爱好**：默认删。保留的唯一判据是能否挂到岗位证据——第 6 例保留「爱好游戏、动漫、唱歌画画，混迹二次元交友圈」，是因为紧接「对 Z 世代年轻人社交需求和心理诉求有深入理解」；第 28 例的「10 年+美术学习经历」被整条删除，说明持续时间长本身不构成保留理由。带证书或等级的兴趣（国家健康瑜伽四段认证、中级教练员）可以作为小项留下，但同样不是保留的充分理由。
- **职业展望**：只写可验证的资质与学习事实（持有 XX 证、参加金牌 HRD 培训、懂阿里 HRBP 方法论）；不写心态形容词和「致力于成为……」「助力战略决策」这类泛化收尾。

## 五、篇幅与格式

| 项 | 标准 |
| --- | --- |
| 段数 | 层数 = 背景 1 + 能力域 n（1～3）+ 产出 0～1 + 荣誉 0～1，上限 5 段；默认 3 段（背景 + 1～2 个能力域）；材料有成果才加产出层，有奖项才加荣誉层 |
| 全块字数 | 材料足够时 150～400 字，一页简历压到 150～300 字；**材料稀疏时按材料量写，允许低于 150 字**，不靠同义复述凑到下限 |
| 单层字数 | 背景 45～130、能力 50～130、产出 70～120、荣誉 45～120；这是提醒线不是硬闸——超出 20% 以内不判问题，全块达标时单层轻微超限不判问题 |
| 字数口径 | 只计 `## 个人优势` 标题下的正文；追问清单、内部说明不计入，也不与正文混排 |
| 行格式 | 每层一个 `- **标签：**内容` 列表项，段内不换行；用户模板要求独立段落时用 `**标签：**内容` |
| 加粗 | 只给段首标签、关键数字、工具名、极值词，其余普通字体 |
| 标点 | 中文全角；段内用分号切分并列事实，句末用句号 |

字数上限是硬约束，不是「尽量精简」。超了先砍能力层的并列项，再砍产出层的第二个案例，最后才动背景层——背景层的量化信息是筛选方最需要的。

`## 个人优势` 块后面必须附一段给用户看的追问（材料没缺项时写「待补：无」），与正文物理分隔（空行 + 「以下内容不粘贴进简历」一行），只列要回问的事实，不写能力缺口。省略这一段等于把缺项留在稿子里。

**正文行内不得出现任何占位符或内部说明**：不写「XX 多万」，也不写「（金额待补，暂不含具体数）」这类括号说明。金额没确认就整句不写这个金额，只写不含金额的可验证状态，把金额与口径放进追问清单。写「待补：无」的同时材料里实际存在缺项（公司名、学历性质、职级、年份等），按缺项处理判 fail。

## 六、材料缺要件时的处理

材料没给的年限、公司层级或名称、奖项年份、金额与口径，一律不推算、不编造、不近似；列入追问清单交给用户，正文按能写的部分写。**缺项是材料问题，不是输出的质量问题**——评审与自检都按「是否把缺项如实回问」判，不按「有没有写全」判。

来源里 11 例保留的 XX / X /（）是出版脱敏，不是写作规范；本 Skill 不交付带占位符的稿子。

## 八、判型：第一层押什么信号

| 类型 | 第 1 层押什么 | 适用场景 | 风险 |
| --- | --- | --- | --- |
| 岗位信号优先型 | 逐条对 JD 任职要求排能力与产出顺序 | 有明确 JD 的精准投递，**默认选项** | 最稳 |
| 背书优先型 | 学历性质、国企/大厂、证书前置 | 国央企、传统行业、校招过筛 | 背书不硬时等于自曝其短 |
| 成果数字优先型 | 量化业绩（营收、增长、转化率、节税额） | 销售、运营、增长、财务岗 | 数字口径必须经得起追问 |
| 稀缺身份优先型 | 创业经历、极值标签、独立产品身份 | 海投、初创公司、没有成熟画像的新岗位 | 大厂 HR 可能嫌不稳 |
| 稳定可靠型 | 年限、连续在职、同城、可到岗 | 国央企、外包驻场、求稳上岸 | 天花板低（来源 28 例没有这类写法，属本 Skill 保留项） |
| 转行桥接型 | 可迁移的年限与行业 + 新方向已完成实操 | 转行者 | 不回答「凭什么转」，HR 替你回答（否定） |

- 有明确 JD 时默认岗位信号优先型，层内顺序跟随 JD 任职要求；JD 匹配看技能关键词与行业/业务垂类两个维度，两者都有时垂类放最前——工具几周能补齐，行业 know-how 不能。
- 海投（无具体 JD）时退到人设型：稀缺身份与成果数字里取更硬的一个。**最硬的那个数字放在第 1 层**，不为它单独开一层——来源第 18 例就是把「组内有效提单量位列第一」直接写在核心经验层里的；单独开一层会把第 1 层抽空，让最硬的信号掉到第四行。海投时缺口层整层删除，动机句也不写（方向由求职意向行承担）。
- 同一份材料里，数字可以分散在多层：第 1 层的数字是「押注信号」，产出层的数字是「案例证据」——两者不冲突，不必把全部数字集中到产出层。
- 转行时，第 1 层写可迁移的年限与行业，第 2、3 层必须出现新方向已完成的实操；不写「为转 X 方向」类动机声明。
- 类型可叠加：主类型定第 1 层，其余类型只贡献单个信号。
- 极值标签必须真实成立，不成立就加限定词收窄到成立；所有信号可验证或有锚点。

## 十、缺口层（可选第 5 段，本 Skill 保留项）

来源 28 例没有缺口/边界写法；这一层来自 2026-10-13 的推荐理由式版本（猎头「objection first」）。保留它，只在有明确 JD 的精准投递时使用，写 1～2 个真实缺口 + 已开始的补强动作：

```text
- **当前缺口：** [缺口事实，对应 JD 的哪条要求]，[已开始的补强动作]。
```

只写真缺口，不写性格短板；缺口必须与目标场景相关（对国企岗不写「无互联网大厂经验」）。海投无 JD 或用户不想暴露短板时整层删除。

## 十一、坏 → 好对照（取自 28 例真实材料）

三例均取自来源案例（个别标点按中文排版规范化），**学校、公司、机构与奖项专名已替换为不可识别的泛称，年限、规模与数字保持原样**；这些内容属于来源案例，不得搬进当前候选人的简历。

### 案例 A 行政高级经理（两段清单变四层事实）

修改前是「专业技能 + 综合素质」两段：证书堆成编号清单、办公软件占一条、能力没有对象、结尾整段是不可验证的自我评价（「具备全局视野、强服务意识及保密原则……展现卓越领导与管理才能」）。

修改后：

```text
- 职业背景：某省属高校统招本硕学历，13 年行政综合管理经验，6 年国企（某国有港口集团）、上市公司（某上市制造企业）行政部一把手任职经历，是懂人力资源、懂经营的行政管理者，最高带过 136人团队。

```

好在哪：背景层一次给齐学历性质、年限、公司层级、职级和管幅；能力层 8 项并列，每项都挂具体对象；产出层有金额和完整成长线；荣誉层全是可查的奖项全称，团队与个人分开写。

### 案例 B 制造业会计（产出层用金额说话）

修改前一句话：「上市制造业总账会计税务会计资产会计工作经验 3 年，能独立完成税务申报及工商年报，熟练掌握用友、金蝶财务软件及办公软件，有中级会计证。」——没有规模、没有结果、把办公软件和财务软件并列。

修改后：

```text
- 核心经验：财务工作经验 10 年，3 年制造业上市公司（新材料）总账会计、税务会计、资产会计经验，在同一家公司试用期提前转正，入职第一年获得新员工成长黑马奖。
```

好在哪：产出层两个案例都是「发现什么问题 → 动作 → 金额」，第二个是出租与自用的横向对比；能力层的 Excel 挂在「函数公式做数据分析」上；奖项（黑马奖、提前转正）并进背景层收尾，没硬造荣誉层。

### 案例 C 客服与内容风控经理（管理岗的层是能力域）

修改前是 6 条编号式自述：2 条是事实（7 年项目运营及服务管理经验、熟练 Office 与 XMind），4 条是形容词与思维自述（语言表达能力强、互联网思维、技术背景、抗压能力强、团队合作精神）。


## 十二、与正文的分工

头部数字是钩子，正文是证据。同一事实在头部只留结论与数字，机制、过程、异常处理留给正文，不重复整段。头部提到的公司、项目与成果，在后文经历里要能对应上。

## 十三、交付前自检

1. 是否冠以 `## 个人优势` 标题，位于联系行之下、专业技能之前？
2. 层数是否按材料定（默认 3 段），有没有硬凑到四层或漏掉材料已有的层？
3. 第 1 层是否给出年限、行业、公司层级或名称、真实角色，并装上押注信号（海投时最硬的成果数字、或岗位相关的覆盖范围）？
4. 每个能力动词后面是否都有具体工作对象？有没有裸形容词、空泛能力词、材料外的对象外扩？并列项是否同类合并、不超过 8 项？
5. **每个能力层是不是只有一个能力域**？同一层里出现两组不同的「动词—对象」对（「掌握法规」与「审查合同」、「团队管理」与「业务管理」）就要拆层。
6. **能力层里有没有残留结果词**？「通过测评 / 公司采纳 / 获批 / 达标 / 获奖 / 绩效 A」必须出现在产出层或荣誉层，出现在能力层就要移走。
7. 产出层是否 1～3 个案例、场景到结果可读、口径清楚、尽量有对比？排名类成果的对象—动作—名次关系是否可读，个人与团队名次是否分清？全块是否至少一处可核对量？
8. 荣誉层的奖项是否写全称？材料没给的年份是否省略并列入追问，而不是编一个？没有荣誉材料时是否不硬设该层，也不拿性格填？
9. 字数是否在预算内（正文全块 150～400，一页版 150～300）、追问是否与正文物理分隔？
10. 语言禁区表是否零命中？每个数字是否能指回原材料、口径是否与材料一致？
11. 是否与正文重复？

只用于一种情况：候选人核心资产是工具链实操而非年限与公司背书，且（互联网/技术岗有明确 JD，或应届转行且新方向已有可展示实操）。写法：3-4 行、全块 ≤200 字、`·` 分隔信号片段、完整句只允许出现在定位结论行、加粗只给工具名与数字；结构为定位结论行 / 匹配点行 2-3 行 / 边界与动机行（无 JD 时删边界行）。回归案例见 `evals/cases.json` 的 `compact_*` 组，评审项见 `evals/advantage-rubric.md` 附录。
