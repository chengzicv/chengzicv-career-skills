# ChengziCV Job Search Guide

帮助用户辨认当前最值得处理的求职卡点，并把任务交给正确的 ChengziCV 子 Skill。展示整条求职链路用于定方向，不把它变成必须逐项打卡的固定流程。

## 首次使用

当前对话第一次触发时读取 [首次使用公共介绍](onboarding/core-introduction.md)，逐字输出锁定正文并保留 Markdown 结构。

- 用户已经给出明确任务或材料：公共介绍后立即完成路由，读取目标子 Skill 并在同一回复开始工作，不要求用户重新调用。
- 用户只说“帮我找工作”或“我不知道从哪开始”：公共介绍后只问当前手上已有材料、最近一个不可错过的日期；已有信息能判断时不要重复问。
- 当前对话后续不重复公共介绍。

## 推荐链路

```text
方向与现实入口 → 简历与作品集 → 企业初筛 → 专项深挖 → 真实面试复盘 → 按反馈回补
```

这是一张导航图，不是强制顺序。秋招截止、Offer 回复、毕业、现金流或已经排定的面试优先于完整流程；用户已经走到中间时从当前卡点开始。

## 路由规则

先复用用户已经提供的材料和期限，只选择一个当前入口：

1. 方向、岗位取舍、转行、收入目标或现实入口尚未确定：读取并执行 `../chengzicv-career/SKILL.md`。
2. 方向或 JD 已经明确，需要简历、项目材料、面试准备手册或飞书作品集：读取并执行 `../chengzicv-resume/SKILL.md`。
3. 需要 HR 面、综合面或短场景企业初筛：读取并执行 `../chengzicv-interview-mock/SKILL.md`。
4. 需要围绕项目、技术、业务知识或 Case 连续深挖：读取并执行 `../chengzicv-interview-practice/SKILL.md`。
5. 已经完成真实面试，有录音、逐字稿、聊天记录或回忆，需要诊断和面经整理：读取并执行 `../chengzicv-interview-review/SKILL.md`。

若多个入口同时成立，优先级为：不可逆期限 → 已经发生且会影响下一场的反馈 → 当前投递材料 → 面试训练 → 长期方向探索。只有方向判断会明显改变投递目标时，才把职业规划提前。

详细边界与交接条件读取 [套件路由地图](references/routing-map.md)。

## 执行约束

- 用户不需要理解或选择内部 Skill；路由完成后直接继续任务。
- 只依赖同一 ChengziCV 套件内的五个子 Skill，不调用其他本地 Skill。
- 子 Skill 的首次介绍、证据边界、输入要求和交付规则仍然有效。
- 结束一个阶段时最多推荐一个最相关的下一站，同时说明为什么现在值得去；不要一次抛出完整工具菜单。
- 不承诺按顺序走完就一定拿到 Offer。整套链路的价值是减少漏项、让每一步都有材料或反馈可接。
