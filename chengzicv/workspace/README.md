# ChengziCV 工作区

这是橙子CV求职套件的工作区说明。安装包只携带本说明，求职档案、上传材料与生成稿默认保存在桌面；桌面不可用时保存在 `chengzicv` 总入口 Skill 内的 `chengzicv-workspace/`，所有子 Skill 共用同一位置。

## 工作区位置规则

首次需要保存材料或产出时才创建工作区，普通问答不创建，不先询问用户是否放桌面。Windows 和 macOS 使用同一规则：

1. 用户已明确指定位置时，使用该位置；否则读取用户主目录下的 `.chengzicv/workspace.json`。配置格式为 `{"version": 1, "root": "工作区的绝对路径"}`。已有配置就继续使用，不因桌面后来可用而自动换目录。配置格式错误、已记录目录不存在或不能访问时，说明原位置并请用户定位或明确新建，不静默创建另一份空工作区。
2. 没有配置时，依次检查两个位置是否已有用户数据：实际桌面下的 `chengzicv-workspace/`、`chengzicv` 总入口实际源目录下的旧 `workspace/`。只有 README、空目录或 `.gitkeep` 不算用户数据。任一处有旧数据就继续使用该位置并记录；两处都有数据时以桌面为准，同时告知用户另一处的存在，不合并、不迁移、不丢弃。用户要求放到桌面时再按迁移规则处理。
3. 没有既有工作区时，读取系统实际桌面位置，确认目录存在且宿主允许写入，使用其中的 `chengzicv-workspace/`。Windows 要识别重定向后的桌面（如 OneDrive 或其他盘），不要写死 `C:\Users\用户名\Desktop`；macOS 使用当前用户实际桌面目录，不假定安装用户或固定用户名。
4. 桌面找不到或不能写入时，使用 `chengzicv` 总入口 Skill 实际源目录下的 `chengzicv-workspace/`，与该入口的 `SKILL.md` 同级；安装入口是链接时先解析到真实目录，不使用当前子 Skill 或当前项目目录。该目录也不能写入时，说明没有保存成功，请用户指定可写位置；完全没有文件能力时使用对话交接摘要。
5. 确定位置后再创建所需的 `profiles/`、`uploads/`、`output/`、`archive/`，并把绝对路径写入 `.chengzicv/workspace.json`。已有同名目录或文件先检查，复用兼容内容，不覆盖同名材料、不把多个求职者的档案混在一起。配置不能写入时说明无法记住位置，不承诺下次会自动恢复。
6. 保存完成后显示实际目录和产物链接，用户说“文件在哪”时读取配置并显示实际位置，不把默认桌面位置当作已经保存的位置。

## 改位置与放到桌面

用户随时可以说“帮我把求职文件放到桌面”或指定其他文件夹。这是迁移工作区的授权，无需额外询问是否创建桌面文件夹。先检查目标是否可写；显示来源和目标，复制工作区文件，逐文件核对完整后更新位置配置，保留原文件。同名内容不同则停止覆盖并让用户选择，失败时保持原配置。桌面不可用时说明原位置继续有效，不声称已经搬到桌面。只要求复制某份简历时，只复制该文件，不改变全套件工作区。

## 目录结构

```text
chengzicv-workspace/
├── README.md             ← 本文件，说明布局
├── current-profile.txt   ← 当前活跃档案的相对路径（如 profiles/张三.md）
├── profiles/             ← 求职档案，每人一份：<姓名>.md
│                          #   只放关键信息：当前阶段、目标岗位、已确认事实、材料索引、缺口、下一步
├── uploads/              ← 用户上传材料的副本（文件名带姓名或日期前缀，保留原文件名主体）
├── output/               ← 所有产出（各版简历、核对报告、小抄、话术、调研稿、面经，文件名带日期）
└── archive/              ← 档案快照与历史版本备份（切换用户、大改前自动留档）
```

## 规则

- **多用户**：一个工作区可服务多名求职者。开始工作前先读 `current-profile.txt` 找到当前档案；从用户材料、文件名或自述判断身份，与当前档案不符时切换到 `profiles/<姓名>.md`（不存在则按模板新建）并更新指针。切换前把当前档案快照存进 `archive/`。
- 档案只维护关键信息；正文太长的内容写成 `output/` 里的独立文件，档案里只留相对路径索引。
- 用户上传的任何文件，先复制一份到 `uploads/` 再处理，原始文件不移动、不改名。
- 每个阶段的产出默认写进 `output/`，文件名带日期或版本号，不覆盖旧版本。用户明确指定交付位置时以用户要求为准，但要在档案的材料索引里记下产物的实际位置。
- 任何 ChengziCV Skill 开始工作前先读当前档案；完成一个阶段后立即更新它。
- 写简历、台词、答案时只能使用档案和 `uploads/` 中已确认的事实；缺的信息问用户，不编。
- 不要把 API Key、身份证号等敏感信息写进任何文件，除非用户明确要求。
