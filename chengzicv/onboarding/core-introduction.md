你好，我是橙子 CV 求职导航。

你可能不是不知道求职要做什么，而是不知道现在该先做哪一步。

简历投出去没回音，面试就在眼前却不知道该练什么；刚面完觉得哪里不对，又说不清问题出在哪；或者几个方向都能讲出道理，就是迟迟选不下来。

这套求职工具一共有 11 个 Skills：1 个总入口帮你判断现在该先做什么，9 个分别处理零材料建档、职业规划、简历与作品集、招聘平台沟通、面试前调研、企业初筛、专项面试、真实面试复盘和岗位案例参考，另外 1 个负责检查和更新整套工具。

### 你现在可以用这些 Skills

- **求职总入口：`$chengzicv`**

  不知道先建档、改简历、练面试还是重新看方向时，从这里开始。我会结合你已有的材料、眼前的机会和不能错过的日期，选出当前最值得处理的一步，并直接开始。

- **零材料求职建档：`$chengzicv-profile`**

  适合还没有简历、材料散在大作业、PPT、奖状和零碎描述里的人。你可以边想边补、随时暂停，并带走一份已经确认的背景、材料索引、待确认项和下一步。

- **职业规划：`$chengzicv-career`**

  适合处理“不知道选什么”“想转行”“几个方向选不下来”或者现实条件与目标不匹配。最后带走的不是一张岗位清单，而是当前要做的决定、少量值得验证的方向和第一个现实动作。

- **简历与作品集：`$chengzicv-resume`**

  把旧简历、JD 或项目材料发来，先整理一版当前事实能够支持的简历，再标出最值得补证据、也最容易在面试中被追问的地方。材料足够时，还可以继续整理项目准备手册和外发作品集。

- **招聘平台沟通：`$chengzicv-job-greeting`**

  把简历、目标 JD 和当前聊天状态发来，直接得到可以发送的 BOSS 直聘等平台开场、回复和跟进话术。重点不是重复学校和届数，而是让招聘者在消息预览里先看到与岗位最相关的事实。

- **面试前调研与冲刺：`$chengzicv-interview-prep`**

  适合公司和岗位已经确定、面试又比较近的时候。它会把公开业务信息、岗位判断和你的真实经历接起来，交付一份能给面试官看的调研稿，以及一份只给自己复习的完整答案冲刺稿。

- **企业初筛模拟：`$chengzicv-interview-mock`**

  用来准备 HR 面、综合面和短场景企业初筛。完成一场贴近目标岗位的模拟后，你会知道企业为什么可能推进、为什么还会犹豫，以及下一轮最需要修正的回答。

- **专项面试训练：`$chengzicv-interview-practice`**

  用来练项目深挖、技术问题、岗位知识、业务分析和 Case。问题会顺着你的回答继续往下走；讲解后还会换一个条件复测，判断你是记住了答案，还是真的会了。

- **真实面试复盘：`$chengzicv-interview-review`**

  把录音、逐字稿或还能记住的问题发来。我会还原面试官在验证什么、追问为什么集中在某些地方，并整理出逐题面经、表现诊断和下一场最值得重练的内容。

- **岗位案例参考：`$chengzicv-case-factory`**

  想先看某个岗位通常做什么、相关经历需要写到什么深度时，用它生成虚拟简历和岗位入门案例。案例只供理解标准，不会被当成你的真实经历。

- **检查与更新：`$chengzicv-update`**

  已经安装过整套工具时，用它检查并同步官方新版本；它不会修改其他来源的 Skills，也不会处理你的个人材料。

### 推荐怎么用

如果你希望按一条相对完整的求职路径推进，可以参考：

```text
零材料求职建档（可选）
→ 职业方向判断（方向不清时）
→ 简历与作品集
→ 招聘平台沟通
→ 面试前调研与冲刺
→ 根据下一轮选择企业初筛模拟或专项面试训练
→ 真实面试复盘
→ 根据反馈回去补材料或继续训练
```

这是一条推荐路线，不是必须全部走完。

- 什么材料都没有，或者想先把大学经历慢慢盘出来，从 `$chengzicv-profile` 开始。
- 方向已经明确，直接从 `$chengzicv-resume` 开始。
- 已经有简历和 JD、正在 BOSS 直聘等平台投递，用 `$chengzicv-job-greeting` 准备开场和跟进。
- 面试已经排定，缺公司理解和完整答案时用 `$chengzicv-interview-prep`；需要现场检验时选择最贴近下一轮的模拟或专项训练。
- 面试刚结束，优先用 `$chengzicv-interview-review`，趁记忆还完整先把反馈留下。
- 完全不知道该选哪个，只调用 `$chengzicv`，不需要自己研究这张地图。

这些 Skills 之间会互相接得上：求职档案留下已经确认的背景和材料；职业方向决定简历该为谁写；简历里的内容可以继续变成招聘平台沟通和面试准备素材；模拟和专项训练继续检验表达与专业能力；真实面试的反馈再决定下一步该补哪里。

如果你希望先把背景和材料慢慢整理起来，我可以把你明确提供的求职信息整理成一份持续更新的求职档案。你可以随时补充、暂停，或者让我输出一份“当前档案摘要”，看看已经确认了什么、还缺什么、下一步最值得做什么。普通聊天不能保证跨会话自动记忆；当前客户端不能长期保存时，我会把摘要完整交给你，下次带回来就能继续。

如果暂时什么都没有，可以只告诉我：你现在是什么背景、最着急解决什么，以及最近有没有不能错过的日期。没有明确日期也没关系。
