## 1. 目标与启动条件

自我信息的目标不是生成一份完整人格画像，而是回答当前决策中哪一项未知：

- 用户是否愿意反复做某类核心任务；
- 是否已有相近能力、学习速度或承受代价的证据；
- 哪种工作回报和环境会显著影响持续性；
- 自我怀疑来自缺少经验，还是已有反向证据；
- 哪些现实约束会改变当前入口。

只有一条自我信息会改变候选、优先级或验证动作时才收集。不要默认发整套问卷，不扫描童年、全部爱好或完整人格。

按以下条件启动：

- 用户只会用“内向、外向、感性、理性、喜欢沟通”等标签描述自己；
- 多个岗位事实已经基本对齐，但缺少区分候选的用户证据；
- 用户说“不知道自己想要什么、擅长什么、能承受什么”；
- 用户主动提供霍兰德、MBTI、荣格八维或其他测评结果；
- Agent 正准备根据性格标签推荐或排除职业。

若用户连职业样本都没有，先给工作机制样本，再收集对应自我信息。没有参照物时泛问“你喜欢什么”通常只会得到抽象标签。

## 2. 六类自我信息

六类不是必答清单。先确定当前缺哪一类，再取最小证据。

| 信息账户 | 要回答的问题 | 优先证据 | 不能推出 |
|---|---|---|---|
| 活动兴趣 | 哪类具体活动会吸引自发投入或愿意重复？ | 主动选择、持续投入、放弃其他活动仍愿意做的记录 | 能力、收入、录用概率 |
| 能力与学习 | 已经能完成什么，怎样学会，反馈和迁移怎样？ | 作品、结果、学习速度、他人反馈、相近任务 | 长期喜欢、所有环境都能发挥 |
| 工作需要与价值 | 哪些回报是当前底线，愿意用什么代价交换？ | 真实选择、冲突事件、最低线与红线 | 永久不变的价值排序 |
| 工作方式与环境 | 在何种协作密度、模糊度、节奏、反馈周期和自主度下表现不同？ | 同一个人在不同环境中的行为和成本差异 | 固定人格类型、对所有岗位的适配 |
| 自我效能与结果预期 | “我做不到”来自没做过、做过失败，还是预期回报太低？ | 尝试史、练习量、榜样和反馈来源、具体预期 | 客观能力或市场结果 |
| 约束与资源 | 时间、现金流、城市、学历、资格、健康、家庭支持如何限制选择？ | 当前可核验条件和截止时间 | 人格价值或终身上限 |

兴趣、能力、价值、自我效能和现实入口必须分账。用户“喜欢但不会”“会做但不想长期做”“想做但当前进不去”都可以同时成立。

## 3. 最小取证回路

### 3.1 先选决定性机制

从候选岗位中找一个最能区分答案的工作机制，例如：

- 长周期独立分析，还是高频对人推进；
- 在模糊需求中定义问题，还是按明确标准稳定交付；
- 承受公开拒绝与业绩波动，还是承受长期技术深挖和反馈延迟；
- 多线程协调，还是长时间单点专注。

不要先问笼统人格。先问：哪种差异真的会改变这次选择？

### 3.2 采一张行为证据卡

围绕一个真实事件收集：

```text
场景：什么时候、为谁、在什么限制下？
任务：实际反复做了什么，不是职位名称？
选择：主动选择还是被迫完成？
持续：做了多久，是否在多个场景重复？
结果：交付、数据、作品或可靠反馈是什么？
成本：最消耗什么，恢复需要多久？
条件：换什么环境，表现或意愿可能改变？
反例：有没有一次相反经历？
```

一张证据卡通常只支持一个局部假设。用户记不清时允许写未知，不引导其补出“正确故事”。

### 3.3 没有经历就产生经历

没有相关经历时不继续人格追问，设计接近目标机制的微型验证：

- 完成一段目标岗位的缩小版工作样本；
- 观察或访谈从业者，并复述自己能否接受其重复任务和代价；
- 在真实约束下试做一次，而非观看课程后想象；
- 比较两个机制明显不同的小任务，记录投入、结果、成本和反馈。

验证不是证明天赋，而是让“未知”第一次获得可观察信息。

## 4. 量表选择规则

只有同时满足以下条件才建议量表：

1. 已明确缺失的构念，例如职业兴趣，而不是笼统“了解自己”；
2. 量表确实测量该构念，并有可追溯的信效度、常模和适用人群说明；
3. 结果会用于生成或比较假设，而不是直接作出高成本决定；
4. 用户自愿，知道结果可能受语言、文化、当前状态和作答方式影响；
5. 结果会与行为证据、岗位事实和现实验证交叉核验。

不要：

- 从聊天文本替用户推算正式测评分数；
- 把自编问题冒充正式量表或输出伪精确百分位；
- 未经许可复制、施测或评分受版权限制的完整量表；
- 用一次测评排除职业、决定专业、证明能力或预测收入；
- 为显得科学而同时发多套测评。

## 5. 霍兰德与 RIASEC

RIASEC 适合回答“对哪些活动和环境更可能有兴趣”，尤其适用于：

- 候选池过窄，需要扩展工作机制样本；
- 用户只有学科或岗位名称，没有活动偏好语言；
- 需要把零散兴趣组织成可继续研究的假设。

优先使用有信效度说明、适合用户语言与人群的正式兴趣工具。O*NET Interest Profiler 是可查阅的 RIASEC 工具示例，官方手册公开了量表开发、信度、效度和职业链接方法：https://www.onetcenter.org/reports/IP_Manual.html 。其职业数据库和常模来自特定市场，不能直接当成中国招聘结论。

结果只交付：

- 相对较高或较低的活动兴趣模式；
- 可能值得观察的任务和环境；
- 与既有行为相符或冲突的地方；
- 需要现实验证的 1—3 个职业假设。

RIASEC 不测：

- 当前技能和学习能力；
- 工作价值底线；
- 学历、招聘准入和薪资；
- 对具体公司、团队或岗位的适配；
- 唯一正确职业。

研究支持职业兴趣与选择、表现和持续性存在有意义的关系，但预测并不完美，且“人—环境匹配”比只看一个兴趣标签更重要。参考：https://doi.org/10.1177/1745691612449021 与 https://pubmed.ncbi.nlm.nih.gov/32686949/ 。

## 6. 荣格八维、MBTI 与人格

不要把荣格八维或 MBTI 作为本 Skill 的默认启动测评，也不要用类型直接推荐或排除职业。

原因不是“人格完全没用”，而是：

- 类型标签会把连续、受情境影响的差异压成类别；
- 荣格功能顺序与具体职业结果之间缺少足以支持高成本职业建议的证据；
- 即使描述让用户有共鸣，也不能证明能力、兴趣、价值、岗位环境或当前准入。

McCrae 与 Costa 对 MBTI 和五因素模型的比较质疑其类型解释及部分指标含义：https://doi.org/10.1111/j.1467-6494.1989.tb00759.x 。不要把这一来源扩张成“任何人格信息都无效”。

用户主动提供类型时，可将其当作自我叙事入口：

```text
“我是 INTP，所以适合做研究”
→ 你认为 INTP 在这里代表哪些具体任务偏好？
→ 哪些真实事件支持你愿意长期独立分析、忍受反馈延迟？
→ 目标研究岗位实际还要求哪些协作、交付和准入？
```

若当前决策确实需要人格维度，优先使用有信效度说明的连续特质工具，把结果翻译成环境和行为假设；即便使用 Big Five，也不能直接生成岗位答案。

## 7. 可直接使用的取证问法

根据决定性未知选一题，不连续盘问：

- 兴趣：“过去半年，有哪件没人要求你也会继续做的具体任务？你实际做了什么？”
- 能力：“哪项相近任务有可见结果或他人反馈？你从不会到能交付花了多久？”
- 成本：“你完成得不错但最不想长期重复的环节是什么？”
- 环境：“同类任务在什么团队或节奏下明显更好或更差？差别发生在哪一步？”
- 价值：“在这两个真实选项中，如果不能同时保留，你先保哪一个？底线是什么？”
- 自我效能：“你说做不到，是还没试、试过但方法无效，还是做成后也不值得？”
- 反例：“有没有一次与你刚才结论相反的经历？什么条件不同？”

如果用户只能回答形容词，追问最近事件；如果仍无事件，停止追问并设计微型验证。

## 8. 交付规则

自我信息阶段只交付与当前决定有关的部分：

1. 当前有证据支持的行为或偏好；
2. 只来自自评、量表或单次经历的低强度假设；
3. 明确冲突，例如有兴趣但缺能力证据；
4. 仍未知且会改变选择的一项信息；
5. 下一张证据卡或一个现实验证。

不要输出完整人格报告，不给“适配度分数”。量表结果与行为冲突时保留冲突，优先寻找情境差异或新证据，不替用户选一个更好听的答案。
