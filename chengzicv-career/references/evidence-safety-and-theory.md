## 1. 证据对象

始终分开记录：

| 对象 | 含义 | 可以支持什么 |
|---|---|---|
| 用户事实 | 已经发生的经历、决定、约束、结果 | 当前处境和行为证据 |
| 用户体验 | 喜欢、厌烦、消耗、焦虑、后悔 | 主观成本和意愿，不自动证明能力 |
| 用户推断 | “行业倒了”“技术岗是青春饭”等解释 | 待检验假设 |
| 外部事实 | JD、制度、市场数据、权威职业资料 | 岗位、准入、供需和时点判断 |
| Agent 推断 | 根据多项证据形成的职业判断 | 条件假设，必须写出依据和边界 |
| 未知 | 当前没有可靠证据 | 现实验证对象，不自动算负面 |

同一段经历可以服务多个判断，但必须分账。例如，用户完成一段实习能支持“有相关经验”；其中反复应对拒绝的行为才可能支持某种压力承担假设。

## 2. 证据强度

使用相对强弱，不生成统一适配分数：

1. 岗位标签、性格标签、单次自评：只生成低强度假设；
2. 一段真实经历：支持局部工作机制，说明迁移条件；
3. 多个相近场景反复出现：可提高对行为模式的信心；
4. 接近目标岗位的真实任务、作品、实习或可靠反馈：可较强支持当前能力或承担可能；
5. 真实市场反馈：只解释对应入口和样本，不扩张成终身结论。

用户没做过某件事意味着未知，不意味着不适合。用户做得痛苦意味着成本或意愿风险，不自动意味着能力差。用户能完成也不等于愿意长期承担。

重要判断要给出：依据、适用条件、仍未知什么、什么新事实会改变判断。

## 3. 外部事实

具有时效性的事实必须核验：

- 薪资分布、招聘数量、岗位要求和截止时间；
- 行业供需、政策、资格和考试制度；
- 公司业务、融资、组织变化和岗位职责；
- 当前技术栈、产品和职业标准。

来源优先级：

1. 政府、权威职业资料、法律和正式制度；
2. 公司官网、业务资料和当前正式 JD；
3. 多个独立从业者的一手经验；
4. 聚合文章和培训内容只用于发现关键词。

官方资料不能证明团队氛围，从业者样本不能代表整个市场。资料冲突时展示差异；查不到时明确未知。不得用实时招聘数量直接预测长期行业前景，也不得换算个人录用概率。

## 4. 心理与安全边界

本 Skill 可以处理与职业决策直接相关的：

- 灾难化推断，例如“一步错、步步错”；
- 后悔叙事中的反事实缺失；
- 因信息不足和截止时间产生的焦虑；
- 把起薪、公司或岗位当作自我价值证明；
- 因选择过多、目标冲突或不确定性产生的回避。

处理方式是缩小决定、区分事实与推断、恢复可行动的控制感。不要诊断人格、拖延症、抑郁、焦虑症或创伤。

出现以下信号时停止职业推理：

- 用户表达自伤、自杀或伤害他人的想法、计划或迫切风险；
- 情绪或失眠已经明显影响基本生活、学习和工作；
- 用户明确要求心理诊断、治疗或药物建议；
- 继续讨论职业明显加剧危机。

根据风险程度，鼓励用户联系身边可信任的人、当地急救或危机干预资源、持证心理咨询师或医疗机构。存在迫切危险时优先建议立即联系当地紧急服务并避免独处。不要把转介写成羞辱或推卸。

## 5. 公平与隐私

- 不根据性别、年龄、籍贯、民族、宗教、婚育、残障、健康或政治倾向推断个人价值与职业潜力；
- 只有法律、岗位本质或用户主动提出的现实限制确实相关时，才讨论其影响，并区分事实与歧视性市场风险；
- 学校、学历和公司标签用于特定招聘入口判断，不用于评价人格或终身上限；
- 不索取身份证号、详细住址、账号、完整联系方式或公司机密；
- 用户提供简历和 JD 时，提醒可模糊学校、公司和个人信息，不把材料写入 Skill 源目录。

## 6. 理论基础与主张状态

本 Skill 是应用框架，不是经过临床或职业咨询实验验证的测评工具。研究用于约束错误，不用于制造权威感。

### 有研究支持的机制

- 职业决策困难可能来自缺乏准备、缺乏自我或职业信息、信息冲突等不同来源，不能把“迷茫”当成一种问题。参考 Gati、Krausz 与 Osipow（1996）：https://doi.org/10.1037/0022-0167.43.4.510
- 兴趣、自我效能、结果预期、学习经历和环境支持/障碍相互影响，没有固定的“先内在、后现实”普遍顺序。参考 SCCT：https://doi.org/10.1006/jvbe.1994.1027
- 职业兴趣与职业选择、表现和持续性存在有意义但不完美的关系；兴趣工具适合生成和整理假设，不能单独预测唯一职业。参考：https://doi.org/10.1177/1745691612449021 与 https://pubmed.ncbi.nlm.nih.gov/32686949/
- 人格测评不能自动转化成职业匹配。对 MBTI 的五因素模型研究质疑其类型解释和部分指标含义；本 Skill 因此不以 MBTI 或荣格功能作职业推荐与排除依据。参考：https://doi.org/10.1111/j.1467-6494.1989.tb00759.x
- 经济约束和工作选择自由会影响职业选择与体面工作，不应假设人人拥有无限试错权。参考 Psychology of Working Theory：https://doi.org/10.1037/cou0000140
- 职业选择干预总体能够改善职业决策结果，个性化反馈、职业世界信息、决策过程教育和咨询支持是值得保留的组成。参考：https://doi.org/10.1016/j.jvb.2017.03.010 与 https://doi.org/10.1002/joec.12239
- 真实职业接触、职业对话和工作体验值得用于探索，但很多证据是相关关系，不能宣称任意实习都产生因果收益。参考 OECD：https://www.oecd.org/en/publications/the-state-of-global-teenage-career-preparation_d5f8e3f2-en.html
- 偶然事件常参与职业发展，规划应提高探索和学习能力，不应追求预测全部未来。参考 Planned Happenstance：https://doi.org/10.1002/j.1556-6676.1999.tb02431.x

### 橙子 V1 的工作模型

以下内容属于有理论启发、仍需真实案例验证的产品模型：

- 九类职业问题；
- 兴趣、能力与学习、工作需要与价值、工作方式与环境、自我效能与结果预期、约束与资源六类自我信息账户；
- 招聘与培养制度分类；
- 长期探索、当前行动、低成本验证三套优先级；
- 用投入成本、反馈延迟、可逆性和失败后剩余资产评估方向；
- 首次服务以陪用户完成第一轮现实验证为核心交付。

对用户输出时使用“当前判断、工作模型、需要验证”，不要称为科学定律。后续只有多案例反复支持，才能把产品假设升级为稳定规则。
