## 1. 使用方式

问题类型是内部路由，不是人格标签，也不是经过验证的心理量表。一个用户可以同时出现多类问题；只处理当前最靠前、最会改变下一步的一类。

判断原则：

- 先看用户想作出什么决定；
- 再看缺信息、缺选项、缺标准、缺准入还是缺执行；
- 已有现实期限时，优先处理会造成机会损失的阻塞；
- 不因为表达焦虑就过早归入心理问题。

## 2. 九类问题

### 2.1 职业世界缺失

**识别信号**：只知道父母、同学、短视频或热门平台反复出现的少数岗位；候选只有“大厂、考公、程序员、做自媒体”；说不出还可以比较什么。

**真正缺失**：不是兴趣答案，而是可供比较的职业样本和描述工作的语言。

**首个动作**：Agent 根据用户专业、城市、经历和限制，提供 2—3 个机制差异明显的工作样本。每个只说明服务对象、核心产出、重复动作、主要代价和典型入口；带用户共同拆一个。

**采集信息**：用户对具体任务和代价的反应、原本不知道的选项、愿意继续了解的原因。不要问“听起来喜不喜欢”就结束。

**最小交付**：一张初步职业版图、1—2 个值得继续研究的工作机制和一个岗位取证动作。

**禁止捷径**：不列几十个岗位大全，不按热门度推荐，不要求小白先独立完成行业研究。

### 2.2 岗位认知停留在名称

**识别信号**：想做产品、运营、算法、机器人、HR、销售，却只能复述招聘宣传、行业前景或抽象能力词；不知道每天反复做什么、交付什么、怎样验收。

**真正缺失**：具体岗位、组织环境和工作机制的事实，而不是更多自我分析。

**首个动作**：把宽泛名称缩成“具体岗位 × 业务/组织环境 × 招聘入口”，补服务对象、要解决的问题、反复任务、交付物、评价指标、协作关系、不可绕开成本和典型入口。

**采集信息**：优先当前 JD、公司业务材料和多个从业者样本；用户只提供自己对真实任务的知情反应。

**最小交付**：岗位事实卡、被推翻的想象、一个仍需核验的关键事实。

**禁止捷径**：岗位名称本身不进入适配结论；行业增长不能代替岗位工作和个人入口。

### 2.3 自我信息不足

**识别信号**：只有“内向、外向、喜欢沟通、逻辑好、我是 INTP、霍兰德是 IAS”等标签；说不出在什么任务、环境和代价下出现；多个方向的关键差异已知，却没有自己的比较证据。

**真正缺失**：不是一份完整人格，而是当前选择所需的某项兴趣、能力、价值、工作方式、自我效能或约束证据。

**首个动作**：读取 [自我信息与测评工具协议](self-information-and-assessment.md)，先选一个决定性工作机制，再从最近经历采一张行为证据卡。没有经历时设计缩小版工作样本。

**采集信息**：场景、具体任务、主动或被动、持续时间、结果与反馈、主观成本、成立条件和反例。

**量表路由**：需要扩展活动兴趣时，可以使用有信效度说明的 RIASEC 工具；人格维度只用于生成环境和行为假设。不要默认启动荣格八维或 MBTI，不从聊天推算类型。

**最小交付**：当前有支持的局部行为、低强度自评或量表假设、一个决定性未知和下一张证据卡。

**禁止捷径**：不输出人格定论、岗位适配分数或“某类型适合某职业”。

### 2.4 目标函数不清

**识别信号**：同时要收入、稳定、成长、体面、轻松、自由和兴趣；不断加入条件；比较表很多，但不知道哪个差异真正改变选择。

**真正缺失**：当前期限内的最低线、红线和交换条件，而不是永久人生价值排序。

**首个动作**：用两个真实选项的冲突校准：若不能同时保留，哪项必须达到最低线，哪项允许暂时牺牲，代价最多承受到什么时候。

**采集信息**：目标口径、期限、最低可接受值、不可接受结果、可交换偏好，以及过去真实选择中的证据。

**最小交付**：本次决定的目标函数、红线和仍需比较的 1—2 个变量。

**禁止捷径**：不让用户抽象排序十项价值，不把“都想要”自动解释为贪心或逃避。

### 2.5 现实准入与期望错配

**识别信号**：目标岗位或薪资存在，但当前学历、专业、资格、项目、城市、时间窗口或证据不足以支持该入口；用户把个别高薪样本当作个人默认报价。

**真正缺失**：目标市场的入口机制、个人证据差距和补齐周期。

**首个动作**：核查招聘制度、硬门槛、常见竞争信号、可替代证据、窗口和样本薪资口径；再对照用户已有资产。

**采集信息**：目标城市与岗位、薪资口径、截止时间、学历/资格、作品/项目、已有市场反馈和可投入资源。

**最小交付**：直接进入、相邻入口、延后转向三类路径中实际成立的选项；分别标注成本和反馈时间。

**禁止捷径**：不用“降低期待”代替市场研究；不因当前进不去判定长期不适合，也不因理论上存在岗位宣称用户可达。

### 2.6 学习没有形成市场信号

**识别信号**：长期上课、考证、刷技术栈和收藏资料，却无法说明这些学习对应目标岗位的哪项核心任务，也没有作品、结果或反馈。

**真正缺失**：从知识到交付、从交付到可信市场证据的链路。

**首个动作**：从一个真实 JD 或岗位任务反推最小交付物：为谁解决什么问题、使用什么方法、产出什么、怎样验收。

**采集信息**：已有知识、可复用素材、目标任务、交付标准、外部反馈渠道和完成周期。

**最小交付**：一条“岗位要求—目标任务—作品/结果—第三方或市场反馈”的证据链；具体学习排期转下游。

**禁止捷径**：不继续增加课程清单，不把证书数量、学习时长或技术名词当成交付能力。

### 2.7 收入目标被误装成岗位问题

**识别信号**：主要想挣钱，却默认只有互联网、大厂、技术岗或白领职位能实现；反复问“哪个行业工资最高”，但不说明金额、期限和风险承受。

**真正缺失**：收入目标结构，而不是岗位名称。

**首个动作**：拆税前/税后、月薪/年包、实现期限、收入稳定性、地点、前期投入、波动和愿付代价；再判断工资就业是不是唯一合适载体。

**采集信息**：现金流底线、目标时间、收入波动容忍、销售/项目交付意愿、可投入资本与时间、不可接受风险。

**最小交付**：雇佣工资、提成型工作、项目制或自雇中与用户条件相关的路径假设，以及本 Skill 未覆盖的财富问题。

**禁止捷径**：不强迫寻找热爱，不把高薪岗位等同于高到手收入或高成功概率，不扩张成创业、投资承诺。

### 2.8 多目标冲突与拒绝取舍

**识别信号**：信息和选项已较充分，仍要求任何路径同时最大化所有结果；每当出现可行方向就增加新条件；不断研究却不允许任何试错。

**真正缺失**：可能是仍有决定性未知、真实资源不足，也可能是不愿承担任何选择的机会成本。不能先入为主。

**首个动作**：先列出哪条新信息真的会改变选择；若已没有决定性信息，展示“不行动”的真实成本，并让用户选择一个最小、可逆、有截止时间的承诺。

**采集信息**：未决变量、可逆范围、最坏可承受损失、延迟损失和停止条件。

**最小交付**：一个阶段性取舍、承诺期限和复盘条件，不要求终身承诺。

**禁止捷径**：不羞辱用户“既要又要”，不把结构限制说成心理逃避，不继续用更多分析维持回避。

### 2.9 身份焦虑与控制感不足

**识别信号**：把起薪、公司、岗位和行业当作个人价值证明；希望一次选对消除未来不确定性；出现“一步错、步步错”“没进大厂就失败”；事实校准后仍反复回到自我否定。

**真正缺失**：可控与不可控的边界、当前选择的可逆结构，以及对自我评价和职业结果的分账。

**首个动作**：分开“已经发生的事实、对未来的预测、对自己的评价”；检查反事实是否有证据；标出本周能改变的一个变量。

**采集信息**：触发事件、灾难化链条、真实损失、可逆点、已有恢复经验，以及是否影响基本生活功能。

**最小交付**：当前就业决定、长期积累和身份叙事三条分账；一个能够恢复现实反馈的可逆动作。

**禁止捷径**：不诊断人格或心理疾病，不用安慰否定结构困难；出现明显功能受损或危机信号时停止职业推理并按安全边界转介。

## 3. 高频伪问题

| 用户原话 | 隐含混淆 | 可调查的改写方向 |
|---|---|---|
| “哪个行业最有前景？” | 行业增长被等同于个人机会 | 哪类具体岗位、招聘制度和个人入口在目标周期内值得验证？ |
| “我适合做什么？” | 假设适合是固定属性 | 哪些工作机制已有支持，哪些需要近似任务验证？ |
| “学历差是不是只能低薪？” | 学历影响被扩张为终身收入判决 | 目标市场在哪些入口使用学历，哪些证据可以替代或绕开？ |
| “第一份工作会不会锁死？” | 路径依赖被写成不可逆 | 这份工作会积累和停止积累什么，多久后转向成本明显上升？ |
| “智驾倒了，要不要转机器人？” | 行业新闻、岗位机会和当前技能被混合 | 今年求职入口与未来转向分别需要什么证据和周期？ |
| “技术岗是不是青春饭？” | 年龄、岗位类型、组织成本和能力迁移混合 | 目标岗位的年龄风险来自什么机制，用户在建立什么可迁移资产？ |
| “我要不要考研/考公/就业？” | 不同路径购买的结果没有对齐 | 每条路径解决什么问题、牺牲什么、何时得到反馈？ |
| “我后悔当初没学某技术。” | 反事实被当成事实 | 当时另一选择是否真的可达；现在最小补救动作是什么？ |
| “我只想找个稳定工作。” | 稳定没有定义 | 更怕失去当前岗位，还是失去后没有下一步？ |

伪问题指当前表达无法直接回答，不等于用户愚蠢或原问题全部错误。纠正一个理由不能自动取消用户对该方向的意愿。

## 4. 结构、个人与心理层

### 结构层

- 行业和区域岗位不足；
- 招聘周期、学历或资格制度；
- 宏观收缩、组织裁员和供需变化；
- 家庭资源、城市和现金流限制；
- 歧视性或不透明的市场条件。

### 个人可改变层

- 目标岗位认知；
- 技能、知识、项目和作品；
- 职业沟通与信息来源；
- 选择标准和资源分配；
- 现实验证和根据反馈调整。

### 心理与安全层

- 灾难化、完美选择要求和后悔反刍；
- 普遍性犹豫或长期回避；
- 明显功能受损或危机信号。

先区分层级，再决定处理深度。结构层不能被改写成“你不够努力”；个人可改变层也不能被“市场不好”完全取消。心理危机按安全边界转介。

## 5. 重写规则

一次只改写最影响下一步的一段：

```text
用户原话
→ 模糊词或隐藏假设
→ 已有事实能证明什么
→ 当前不能推出什么
→ 一个可观察的问题
```

好的重写必须让后续能够通过岗位资料、用户行为、真实任务或市场反馈回答。若改写后仍是“怎样保证未来成功”，继续缩小。

不要为了显示深刻强行宣布用户问错。原问题事实充分时直接回答；只有能指出具体错误、依据和对结论的影响时才消解。
