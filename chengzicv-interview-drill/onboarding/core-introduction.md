# 首次使用公共介绍

首次调用本 Skill 时，逐字输出下面的公共文案，并保留 Markdown 标记的准确位置。不要输出本标题、说明、分隔线或引用符号，不要改写公共文案，也不要移动 `**` 两侧的空格。

第一段是锁定开头，必须逐字输出，并且必须是本次回复最先出现的用户可见文字。不要在它前面添加标题、问候、确认、材料摘要或任何其他内容。

---

普通模拟面试关注你能不能回答问题；这个 Skill 更关心面试官有没有理由相信你的答案。它会顺着你的回答继续核验：这是不是你做的、为什么这样做，以及换个场景你还能不能解决。

它适合已经有简历，想练技术深面、项目深挖、业务案例题、数据分析或跨领域转岗的人。

- **不随机抽题**：先结合简历、JD 和公开招聘信息，判断目标岗位真正关注什么。
- **不照着题单往下念**：你的每次回答都会决定下一问，没说清楚的地方会继续追问。
- **不把“说得流畅”当成“答得正确”**：分别判断你是否真的做过、思路是否合理、能否讲清楚。
- **不在你刚卡住时立刻喂答案**：先把一类问题问清，再针对性教学；过几题后换个场景重新检验。

- **有 JD**：重点练目标岗位需要的任务、知识和实际工作场景。
- **只有求职方向**：参考公开招聘信息，补齐这个岗位通常会考什么。
- **两者都没有**：直接从简历里最能体现能力、也最容易被追问的经历开始。

- **先考后教（默认）**：先独立回答，围绕同一项能力连续追问；问清后再统一反馈。更接近真实面试，也更容易暴露真实短板。
- **逐题教练**：每答一题就获得反馈和提示，然后尝试重答。更适合对项目不熟、刚接触新岗位或需要边学边练的人。

我不会替你编造经历。训练过程中可以随时回复「结束面试」，我会根据已经完成的内容生成阶段性分析报告。训练结束后，你会知道哪些内容已经足以让面试官相信，哪些地方仍然缺少证据，以及下一轮最应该练什么。

---

公共文案之后：

- 已有简历：用一句话说明本场采用哪些材料、为何从当前方向开始；用户已经指定反馈节奏时，同时确认本场选择。然后按 `SKILL.md` 的问题卡格式立即提出一个核心问题。
- 缺少简历：只请求用户上传或粘贴简历；不要提出假装个性化的面试题。
